# Fairblox MVP

## Positioning

Fairblox is a simpler creator platform for small multiplayer games with faster publishing and fairer discovery.

## MVP Focus

- browser-first
- obby/minigame template
- fake currency only
- creator dashboard
- admin moderation

## Roles

- players
- creators
- admins

## Core Pages

- homepage
- game page
- profile
- creator dashboard
- editor
- admin queue

## Core Services
